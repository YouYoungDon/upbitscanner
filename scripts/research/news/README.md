# 공식 상장 공지 → 업비트 KRW 가격 효과

news-watch가 알림만 보내는 공식 상장 공지(`official-listing`)를 점수에 더할지 판단하기 위한 측정이다.

```
node scripts/research/news/listing-effect.mjs
```

- 필요 데이터: `data/research/candles.json` (`scripts/research/signal-ablation/fetch.mjs`로 생성, 일봉 ~600일)
- 공지: 업비트 api-manager(trade 카테고리, 최대 60페이지), 바이낸스 CMS catalog 48(신규 상장, 최대 15페이지). 바이낸스 목록 API는 발행 시각이 비어 있어서, 상장으로 분류되고 업비트 코인에 매칭된 공지만 상세 API로 `publishDate`를 조회한다.
- 수익은 같은 날 전 종목 평균 대비 초과수익이다(±50% 윈저라이즈).
- "당일종가 진입"은 공지 당일 확정 종가에 사는 현실적인 진입이다. "전날종가"는 공지를 미리 알아야 가능한 값이라 **참고용**이다.

## 해석

- **업비트 KRW 신규 상장은 당일 종가에 사면 뚜렷하게 손해다.** 표본 140건, 1·3·7일 모두 음수, 승률 20% 안팎이다. 전형적인 "상장 펌핑 후 하락"이다. 점수 가산 근거는 없고, 오히려 상장 직후 며칠은 매수 후보에서 조심해야 한다는 신호에 가깝다.
- **바이낸스 상장은 표본이 5~6건이라 결론을 내리지 않는다**(기준: 유형당 20건 이상). 방향은 당일종가 진입 시 음수다. "전날종가"가 크게 양수인 것은 공지 전에 이미 오르기 시작했거나(정보 선반영) 공지 당일 급등을 포함하기 때문이고, 공지를 보고 사는 우리에게는 해당되지 않는다.
- 분 단위 진입(공지 직후 몇 분 안)은 이 측정에 없다. 일봉 기준으로는 "공지 뒤 추격"이 손해라는 결론이고, 이는 일봉 재생(과열 회피)·자금유입 재생(급등 신호 = 급락 신호)과 같은 방향이다.

**결론: 공식 상장 공지는 지금처럼 알림만 하고 점수에는 넣지 않는다.** 가산 여부는 사용자 결정 사항으로 남긴다.
