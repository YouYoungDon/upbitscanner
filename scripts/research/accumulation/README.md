# 매집 신호 측정 (2026-10-08 스파이크)

질문: "돈이 들어오고 있다 = 매집 중"을 무료 데이터로 잡아 급등 전에 살 수 있나?
대상: 업비트·바이낸스 동시 상장 199종목, 2025-02~2026-10. 판정 4요건(시장 대비·진입일 군집 t·비용 0.3%·전/후반).

```
node fetch-binance.mjs                       # 바이낸스 USDT 일봉(테이커 매수 거래대금 포함) → data/research/binance-1d.json
node measure.mjs                             # 기본: 신호일 종가 진입
DELAY=1 MINTV=5000000000 node measure.mjs    # 강건성: 하루 늦게 진입, 30일 평균 거래대금 50억 이상만
```

## 결과

- **테이커 순매수(바이낸스 시장가 매수 비율·7일 순매수)**: 어떤 형태(상위 20%, 횡보 중 순매수)로도 4요건 미통과. 매집 신호로 쓸 수 없다.
- **코인별 김치 프리미엄(BTC 대비) 상승·평소 대비 초과**: 신호일 종가 진입에선 t 5~10으로 강했지만, 하루 늦게 진입하면 대부분 사라진다 → 당일 안에 끝나는 되돌림(체결가 지연·호가 튐 포함).
- **예외 — BTC 대비 프리미엄 +3% 이상(대시보드 🇰🇷 과열 플래그와 같은 기준)**: 하루 늦게 진입·거래대금 50억 이상으로 좁혀도 3일 −2.3~−3.8%p, 7일 −4.0~−6.5%p, 모든 칸 t ≤ −2.2. **회피 신호로 4요건 통과.**
- 가설은 반대로 확인됐다: 한국 돈이 특정 코인에 몰리는 것(프리미엄 상승)은 매집이 아니라 늦은 추격이고, 이후 시장보다 부진하다.
- 한계: 현재 상장 코인만(생존 편향), 바이낸스 미상장 83종목은 측정 불가.
